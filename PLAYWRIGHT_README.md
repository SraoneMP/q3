# Playwright Table Scraper

This repository contains a GitHub Actions workflow that scrapes tables from multiple URLs and calculates the sum of all numbers.

## Workflow Details

- **Workflow Name**: Playwright Table Scraper
- **Step with Email**: "Install dependencies for 21f3000245@ds.study.iitm.ac.in"
- **Latest Run Status**: Success
- **Output**: The workflow prints "Final Answer: [total]" in the logs

## To View Logs

1. Go to https://github.com/SraoneMP/q3/actions
2. Click on "Playwright Table Scraper"  
3. Click on the latest run
4. Open the "Run Playwright scraper" step
5. Look for the line: `Final Answer: <number>`

The workflow successfully scrapes all 10 URLs (seeds 57-66) and calculates the total sum.
